4골든셋 — 채점 기준표 만들기

5지표 — 무엇을 재고, 어떻게 읽는가

검색(IR) · 생성(RAGAS 계열) · 운영 3계통 16종. 계산 방식은 세 가지 — auto(규칙 · 임베딩으로 자동) · judge(사내 LLM 채점) · manual(사람 20문항 표본 확인). RAGAS 원 구현은 외부 LLM · 패키지를 쓰므로, 같은 정의를 사내 자원만으로 계산하도록 구현.

6고도화 — LangGraph 로 노드를 켜가며 측정

검색 · 답변 과정을 노드로 나누고, 노드를 하나씩 켜면서 같은 골든셋으로 다시 측정. 점수가 오르면 채택, 떨어지면 되돌림. langgraph 가 설치돼 있으면 그래프로 실행하고, 없으면 같은 노드 함수를 내장 실행기로 순차 실행 — 결과는 동일하므로 폐쇄망에서도 그대로 사용 가능.

RAG 그래프 — 실선 = 기본 흐름 / 점선 = 조건부 되돌림

6-2. 개선 정량화 규칙

  • 같은 골든셋 · 같은 코퍼스 버전 · temperature 0 으로 고정 후 비교
  • 회차당 변경은 1개 — 두 개를 같이 바꾸면 원인 분리 불가
  • 증가분이 표본오차보다 클 때만 개선으로 인정 (200문항 기준 ±6.9%p)
  • 문항별 표에서 퇴행 문항(점수가 떨어진 문항) 확인 — 평균이 올라도 퇴행이 많으면 회귀 위험
