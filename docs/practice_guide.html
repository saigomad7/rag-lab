밖에서 먼저 돌려보기

LLM 없이, 고정된 샘플 데이터와 고정된 정답지로 이 코드가 어떻게 도는지 확인합니다. 설정할 것 없고 키도 필요 없습니다. 압축 풀고 바로 실행하면 됩니다.

목적 — 성능을 측정하는 게 아니라 구조를 이해하는 것입니다. 값을 하나씩 바꿔 보며 "무엇을 건드리면 점수가 어떻게 움직이는지"를 손에 익힌 뒤, 그 감각을 사내 DB로 가져갑니다.

2준비 — 2분

  1. 압축 풀기경로에 한글·공백 없는 곳 권장 (예: C:\work\rag_lab)
  2. 패키지Spyder 콘솔에 %pip install pandas numpy openpyxl — 이 셋뿐입니다
  3. 끝.env 만들 필요 없습니다. 키도 필요 없습니다.
확인 — 아무 노트북이나 열어 [0] 준비 셀을 실행했을 때 LAB_MODE = sample 과 SAMPLE_SET = 100 이 찍히면 정상입니다.

3순서 — 다섯 개만 돌립니다

Spyder 에서 파일을 열고 Ctrl+Enter 로 셀을 하나씩. 반드시 [0] 준비 셀부터.

지표묻는 것읽는 법
hit@1첫 번째가 정답이었나0.667 = 30문항 중 20개를 1위로 맞힘
hit@5상위 5개 안에 정답이 있었나"찾기는 찾았나"
recall@5정답 문서를 몇 %나 회수했나정답이 여러 개인 문항에서 의미
mrr정답이 몇 번째로 나왔나0.76 → 평균 1.3번째. 1.0이면 항상 1위
샘플 모드의 dense는 낮게 나오는 게 정상입니다. 진짜 임베딩 모델 대신 해시로 흉내 낸 것이라 그렇습니다. 사내에서 BGE-M3를 붙이면 이 값이 올라갑니다. BM25 계열 숫자는 진짜이므로 그쪽을 보십시오.

6사내로 가져갈 때

밖에서 익힌 그대로, 데이터 원천만 바꿉니다. 노트북은 고치지 않습니다.

고칠 것무엇을
.envOracle 접속 · Milvus 주소 · 사내 LLM 주소 · LAB_MODE=live
lab_config.pyRAW · CHUNK · MV — 왼쪽은 그대로, 오른쪽만 사내 테이블·컬럼 이름으로. 없는 컬럼은 None, 더 있으면 줄 추가
lab_sources.pySOURCES — 사내 카테고리로. 항목을 넣으면 생기고 지우면 없어짐. alias에 사내 DB 값(News, research 같은)을 적음
golden_v1.csv사내 문서로 만든 정답지. 밖에서 쓴 golden_sample100.csv와 같은 열 구조
사내에서 첫 실행 — nb00_pipeline_check부터. [1b] 셀이 사내 DOC_TYPE 값이 전부 인식됐는지 알려 줍니다. "정의 없음"이 있으면 lab_sources를 먼저 고치십시오.
