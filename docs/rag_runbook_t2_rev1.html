3질문이 답이 되는 길

도식 4 · 검색 · 생성 파이프라인

점수와 단계의 대응 — Recall 이 낮으면 ①~④, MRR 이 낮으면 ⑤, 답변만 이상하면 ⑦ ⑧ 을 본다. 6장에서 지표별로 다시 정리한다.

BM25 — 글자 그대로 찾기

질문에 쓴 단어가 문서에 있는지로 점수를 매김

  1. 강점 — 제품명 · 코드 · 고유명사에 정확함
  2. 약점 — "증설"로 물으면 "캐파 확대"를 못 찾음
  3. 한국어 함정 — 조사가 붙어 "HBM을"과 "HBM"이 다른 단어로 취급됨
  4. 처방 — 형태소 분석기(Kiwi) 적용 후 재측정 (nb03)

사내에 형태소 분석기 설치가 어려우면 조사 제거 방식으로도 상당 부분 회복됨

시맨틱 — 뜻으로 찾기

문장을 숫자 벡터로 바꿔 가까운 것을 찾음

  1. 강점 — 표현이 달라도 같은 뜻이면 회수
  2. 약점 — 고유명사 · 숫자를 흐릿하게 처리해 엉뚱한 문서를 올림
  3. 함정 — 청크가 임베딩 최대 길이를 넘으면 뒤가 조용히 잘림
  4. 처방 — 토큰 p95 확인 후 청크 크기 조정 (nb00 · nb02)

둘은 실패하는 지점이 다름 — 그래서 합쳐서(하이브리드) 쓰는 것

+용어 풀이

이 문서에 나온 말 12개

회의에서 그대로 쓸 수 있는 수준으로만 정리.

청크 chunk

문서를 검색 단위로 자른 조각. 문서 1건이 여러 청크가 되고, DOC_ID 로 원문에 연결된다. 검색은 청크 단위로 이뤄진다.

임베딩 embedding

문장을 숫자 벡터로 바꾸는 것. 뜻이 비슷하면 벡터도 가까워지므로, 표현이 달라도 찾을 수 있다.

하이브리드 검색

단어 일치(BM25)와 뜻 유사도(시맨틱)를 함께 쓰는 방식. 둘은 실패하는 지점이 달라서 합치면 서로를 보완한다.

RRF 결합

서로 다른 검색기의 순위를 하나로 합치는 규칙. 점수 단위가 달라도 순위만 쓰므로 안전하다. 위치는 ④ 결합 단계.

리랭크 rerank

1차로 넓게 가져온 후보를 질문 · 문단 쌍으로 다시 채점해 순서를 바로잡는 것. Recall 보다 MRR · nDCG 를 올린다.

MMR 다양성

비슷한 내용이 상위를 독점하지 않도록 중복을 접는 것. 리랭크 다음 단계이며 RRF 와는 자리가 다르다.

골든셋

질문 + 정답 + 근거 문서가 갖춰진 채점 기준표. 이것이 없으면 점수를 낼 수 없고, 근거가 없으면 점수를 해석할 수 없다.

Recall@k

정답 문서가 상위 k개 안에 들어온 질문의 비율. "찾았는가"를 재는 가장 기본 지표. 기준 R@5 ≥ 0.80.

MRR

첫 정답이 몇 번째로 나왔는지의 역수 평균. 1위면 1.0. "몇 번째로 찾았는가"를 잰다.

충실도 Faithfulness

답변 문장 중 근거 자료에 실제로 있는 내용의 비율. 낮으면 지어낸 것. 기준 ≥ 0.85.

거절 정확도 Refusal

자료에 없는 질문에 "확인된 자료 없음"이라고 답한 비율. 모르는 것을 모른다고 하는 능력.

프리셋 preset

노드 구성 묶음(v0~v6). 하나씩 켜가며 같은 골든셋으로 재면 무엇이 얼마나 기여하는지 분리된다.
